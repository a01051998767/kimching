# 함께 담그는 비건 행복김치 🥬 참가신청 페이지

모바일용 참가신청 한 장짜리 페이지예요. 신청 내용은 구글 시트에 쌓여요. 서버도, 돈도 필요 없어요.

| 파일 | 역할 |
|---|---|
| `index.html` | 참가자가 보는 페이지 (안내 · 현황 · 신청서 · 레시피 · 참가비 계산기) |
| `Code.gs` | 구글 시트에 붙여넣는 Apps Script (신청 저장, 현황 숫자 제공) |

## 먼저 화면만 보고 싶다면

`index.html`을 더블클릭해서 브라우저로 열면 돼요. `APPS_SCRIPT_URL`이 비어 있으면 **가짜 데이터 모드**로 동작해요 (맨 위에 노란 띠가 보여요). 신청해도 내 브라우저에만 저장돼요.

- 마감 뒤 화면 미리보기: 주소 끝에 `?today=2026-11-25` 를 붙여요.
- 실제 URL을 넣은 뒤에도 가짜 모드로 보려면: 주소 끝에 `?mock=1` 을 붙여요.

## 설치 (약 10분)

### 1단계. 구글 시트 만들기

1. <https://sheets.new> 를 열어요. 새 시트가 만들어져요.
2. 왼쪽 위 제목을 `비건 김장 신청` 처럼 알아보기 쉽게 바꿔요.

### 2단계. 스크립트 붙여넣기

1. 시트 메뉴에서 **확장 프로그램 → Apps Script** 를 눌러요. 새 탭이 열려요.
2. 편집기에 있는 `function myFunction() { }` 를 **전부 지우고**, 이 저장소의 `Code.gs` 내용을 **통째로 복사해서 붙여넣어요.**
3. 💾 저장 아이콘을 눌러요 (Ctrl+S).
4. 위쪽 함수 고르는 칸에서 **`setup`** 을 고르고 **▶ 실행**을 눌러요.
5. 처음이라 권한을 물어봐요.
   - **권한 검토** → 내 구글 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음)** → **허용**
   - 내가 만든 스크립트가 내 시트에 쓰는 걸 허락하는 거라 걱정하지 않아도 돼요.
6. 시트 탭으로 돌아가면 아래에 **`신청`**, **`요약`** 탭이 생겨 있어요.

### 3단계. 웹앱으로 배포하기

1. Apps Script 화면 오른쪽 위 **배포 → 새 배포** 를 눌러요.
2. "유형 선택" 옆 ⚙️ 톱니바퀴 → **웹 앱** 을 골라요.
3. 이렇게 설정해요.
   - 설명: 아무거나 (예: `김장 신청`)
   - **다음 사용자 인증 정보로 실행: 나**
   - **액세스 권한이 있는 사용자: 모든 사용자** ← 이걸 꼭 "모든 사용자"로 해야 참가자들이 신청할 수 있어요.
4. **배포** 를 누르고, 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사해요.
5. 확인: 그 URL을 브라우저 주소창에 붙여넣어 열었을 때 `{"ok":true,"closed":false,"count":0,"heads":0}` 비슷한 글자가 보이면 성공이에요.

### 4단계. index.html에 URL 넣기

`index.html`을 메모장 같은 편집기로 열고, 맨 위쪽의 이 줄을 찾아요.

```js
APPS_SCRIPT_URL: "",
```

따옴표 사이에 복사한 URL을 붙여넣고 저장해요.

```js
APPS_SCRIPT_URL: "https://script.google.com/macros/s/…/exec",
```

이제 페이지를 열면 노란 띠가 사라지고 실제 시트에 저장돼요. 테스트로 한 번 신청해 보고, 시트 `신청` 탭에서 그 줄을 지우면 돼요.

## 페이지 올리기 (둘 중 하나)

**GitHub Pages**

1. 이 저장소 GitHub 페이지에서 **Settings → Pages** 로 가요.
2. Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 **Save**.
3. 1~2분 뒤 `https://(아이디).github.io/(저장소이름)/` 주소로 열려요.

**Netlify**

1. <https://app.netlify.com/drop> 을 열어요 (가입 필요).
2. `index.html`이 들어 있는 폴더를 통째로 끌어다 놓으면 바로 주소가 나와요.

## 운영자가 알아둘 것

### 시트 보는 법

- **`신청` 탭**: 신청시각 · 이름 · 연락처 · 포기 수 · 하고 싶은 말 · **예상 참가비** · 수정시각
- **`요약` 탭**: 총 인원, 총 포기 수, 절인배추 박스 수, 예상 총 재료비, 예상 참가비 총액, 차액이 수식으로 자동 계산돼요.
- 신청을 취소 처리하려면 `신청` 탭에서 그 **행을 통째로 삭제**하면 돼요 (행 번호 오른쪽 클릭 → 행 삭제).
- 같은 연락처로 다시 신청하면 새 줄이 생기지 않고 기존 줄이 고쳐져요.
- 장보기 목록은 페이지의 **레시피 → 장보기 목록**을 펼치면 총 포기 수에 맞춰 나와요.

### 금액·마감일을 바꾸고 싶을 때

두 군데를 **똑같이** 고쳐야 해요.

1. `index.html` 맨 위 `CONFIG` (`BASE_FEE`, `PER_HEAD`, `HEADS_PER_BOX`, `DEADLINE`)
2. `Code.gs` 맨 위 `CONFIG` → 고친 뒤 **`setup` 다시 실행** (신청 내역은 그대로 남아요)
   → **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** (URL은 그대로예요)

> ⚠️ Code.gs를 고친 뒤 "새 버전"으로 다시 배포하지 않으면 바뀐 내용이 적용되지 않아요.

### 레시피 분량을 바꾸고 싶을 때

`index.html` 맨 위 `RECIPE` 목록에서 `label`(화면에 보이는 글자)과 `per`(계산용 숫자)를 같이 고치면 장보기 목록도 따라 바뀌어요.

### 개인정보

- 페이지에는 **인원 수와 포기 수 숫자만** 나와요. 이름·연락처는 시트에만 있어요.
- 시트는 다른 사람과 공유하지 마세요. 행사가 끝나면 `신청` 탭의 내용을 지우거나 시트를 삭제해 주세요.

### 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| "현황을 불러오지 못했어요" | 3단계에서 액세스 권한을 **모든 사용자**로 했는지, URL이 `/exec`로 끝나는지 |
| 신청하면 저장 실패 | `setup`을 실행했는지 (`신청` 탭이 있는지) |
| 코드를 고쳤는데 그대로 | 배포 관리에서 **새 버전**으로 다시 배포했는지 |
